# Reflet

*A puzzle of twin lights — « Jeux impossibles » series.*

One command drives two fireflies at once. The amber one obeys you; her teal
twin plays every order **in mirror** — when you step right, she steps left.
Up and down are shared. Walls stop each sister separately: block one to break
the mirror, desynchronise the pair, and bring **both** fireflies to their
matching portals **at the same time**.

## How to play

- Move with the **arrow keys**, **WASD** or **ZQSD**; on touch screens,
  **swipe** on the board or use the on-screen pad.
- Every move drives both fireflies: horizontal orders are mirrored for the
  teal twin, vertical orders move both the same way.
- The sisters never collide: they cannot swap cells, and both halt when they
  aim for the same cell.
- Amber → amber portal, teal → teal portal. Both home at the same time wins
  the level. **U** undoes a move, **R** restarts.
- Fewer moves, brighter stars: ★★★ at par, ★★ within par+3.
- 13 levels, each solvable — the `par` of every level is the optimal move
  count, proven by a BFS solver (see Tests).

Interface in **English** (default), **French** and **Spanish**.

## Run locally

Everything is static and self-contained (no network). `index.html` is the
published autonomous bundle required by LOB7 (styles and scripts inlined); it
is **generated** from the sources by `tools/build.py` — never edit it by hand:

```bash
python tools/build.py            # rebuilds index.html from index.src.html + assets/
python -m http.server 8127       # then open http://localhost:8127/
```

## Tests

The rules engine (`assets/engine.js`) is pure JavaScript, shared by the browser
UI and the Node test suite:

```bash
node --test tests/engine.test.mjs
```

Covered: mirrored movement, per-firefly wall blocking, contested cells,
forbidden swaps, following into a vacated cell, simultaneous-win detection,
undo, and every level's solvability with `par` equal to the BFS optimum.

## Project structure

```

assets/i18n.js         EN / FR / ES strings
assets/audio.js        tiny WebAudio synth (no audio assets)
assets/ui.js           screens, board, inputs (keyboard, swipe, d-pad)
tools/solve.mjs       solver used while designing the levels
tests/engine.test.mjs rule tests + level proofs

LOB7-ATTRIBUTION.json LOB7 attribution (schema v1)
cover.png             cover (generated by tools/make_cover.py)
```
